# 🥄 TinySpoon

> A location-based MPASI (complementary food) marketplace app connecting parents with certified local sellers.

## 📱 About
TinySpoon helps busy parents find and order safe, nutritious baby food from verified UMKM sellers, filtered by baby age, texture, and nutritional content.

## 🗂️ Project Structure
tinyspoon/
├── android/ # Kotlin + Jetpack Compose mobile app
└── backend/ # NestJS + Supabase REST API
